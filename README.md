# Durtup Official Online Shopping Platform

A modern React + Vite + TypeScript e-commerce platform with automated wholesale dropship supplier integration, reseller capabilities, and AI shopping assistance.

## Features

- **Storefront:** Dynamic category filters, product listing, search, wishlist, cart, and custom checkout flow.
- **Admin Panel:** Complete inventory management, custom margin configuration, order management, and dropship supplier integrations.
- **Wholesale API Integration:** Automated product syncing, category mapping, and automatic order forwarding on customer checkout.

## Technologies Used

- **Frontend:** React, Vite, TypeScript, Tailwind CSS, Radix UI, Lucide Icons, React Query, React Hook Form
- **Backend/Database:** Supabase (PostgreSQL, Storage, Edge Functions)

## Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) and npm installed.

### Installation

1. Clone the repository:
   ```sh
   git clone <YOUR_GIT_URL>
   cd nahid-drems-project
   ```

2. Install dependencies:
   ```sh
   npm install
   ```

3. Start the local development server:
   ```sh
   npm run dev
   ```

4. Build the application for production:
   ```sh
   npm run build
   ```
