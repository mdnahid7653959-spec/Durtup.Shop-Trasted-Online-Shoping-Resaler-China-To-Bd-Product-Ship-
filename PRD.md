# PRD: Durtup Enterprise Marketplace Platform

## Overview
Durtup Official Online Shopping Platform & Enterprise Marketplace (China to BD product shipping, reseller, customer portal, and admin management).

## Tasks & User Stories

### Task 1: Admin Panel Web Browser Access
- Resolve the admin gate restriction to allow seamless browser access to `/admin` and `/admin/login` with username & password authentication.
- Verify session handling and role protection.

### Task 2: Supabase Realtime & DB Sync
- Ensure dynamic revenue stats and order status synchronization between customers and admin.
- Verify RLS policies and secure anonymous tokens.

### Task 3: Mobile PWA & Push Notifications
- Verify PWA install banner and sound notifications on new orders.
- Validate Capacitor native integrations for mobile views.
